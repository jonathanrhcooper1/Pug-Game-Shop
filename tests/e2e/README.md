# Playwright End-To-End Tests

Required user journeys:

- Admin dashboard and system status.
- Inventory search and item detail.
- Kiosk event/detail/cart flow.
- Exact-item cart reservation and checkout handoff.
- Event registration and waitlist flow.
- Customer credit lookup and redemption.
- Buylist intake and staff review.
- Staff event check-in and QR scan workflow.

Use local or staging test data only. Production customer, payment, inventory,
event, and credit data must never be used in E2E tests.
